# image processor

This is a simple image processor for basic image manipulation tasks. The goal is to learn, scaling concepts, so I will not try 
to reinvent the wheel in terms of image processing. 

The goal is to:
- Authenticate with Spring Security
- Cache processed images in Redis
- Use RabbitMQ to process images asynchronously
- Use Spring Data JPA to store image metadata in a database
- Store images in a s3 instance, that will be run locally using minio.
